## Текущее состояние (Day 12 завершен)
- **Backend:** Модель `UserItem` (пины, экипировка, заточка). Статы экипировки суммируются. API инвентаря готово.
- **Frontend:** Drag & Drop на кукле, двойной клик, фильтрация по слоту. Визуал заточки BDO (D, C, B, A, S).
- **Infra:** Docker, CI (был пофикшен фиксом типов).
