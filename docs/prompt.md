## Текущее состояние (Day 11 завершен)
- **Backend:** `talent_tree.json` (v2) с поддержкой per-rank эффектов. Работают API для статов и инвентаря. JSON-база предметов (100 шт).
- **Frontend:** `/character` — полноценный дашборд (семиугольник, кукла экипировки, сетка инвентаря 4x6, достижения). Инвентарь умеет закреплять предметы. Дерево талантов работает на схеме v2.
- **Infra:** Docker, CI зелёный.
