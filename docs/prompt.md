## Уроки Day 7 (чтобы не повторять ошибки)
1. **Vite 8 + Vitest:** `defineConfig` из `vitest/config` конфликтует с плагинами Vite 8 (Rolldown). Решение — разделять конфиги через `mergeConfig` в отдельном `vitest.config.ts`.
2. **Пустые тесты:** Vitest падает с кодом 1, если нет ни одного тестового файла. Лечится флагом `--passWithNoTests`.
3. **Структура тестов:** Во фронтенде принято держать тесты рядом с тестируемыми файлами (`constants.ts` -> `constants.test.ts`), а не в отдельной папке, как в бэкенде.
